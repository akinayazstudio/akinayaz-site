# akinayaz.com

Akın Ayaz kişisel sanatçı sitesi (v3). Statik HTML/CSS/JS; `main` dalına her push Hostinger'da `public_html`'e otomatik yayınlanır.

- `index.html` – tek sayfa: giriş + Resim · Arşiv · Fotoğraf · Projeler · Atölye · Sergiler · Hakkında (TR/EN)
- `assets/data.js` – eserler, gruplar, künyeler
- `assets/v3.css`, `assets/v3.js` – stil ve davranış
- `assets/w/` – görseller, `assets/v/` – videolar
